# 知识库四阶段开发

四阶段已按顺序实现，使用说明见 [检索、知识链接与持续研究](knowledge-research.md)。

1. 本地中文 Embedding、持久化向量索引、增量重建/进度/取消、关键词与向量融合、可编辑的检索评测集及 Recall@K/MRR 对比。模型首次下载，之后片段和向量计算留在本机；未就绪时明确回退关键词检索。
2. 文章/个人笔记/研究笔记/主题页的显式链接与 `[[双向链接]]` 解析，反向链接，歧义和失效目标提示；可编辑主题知识页与带出处的 AI 更新草稿。
3. 受限 Markdown 目录互通：按稳定 ID 导出文章和笔记，保留元数据、附件和来源；导入预览、批量导入、外部变化检测、冲突保留、禁止路径越界，不自动覆盖双方编辑或删除本地文章。
4. 持续研究项目：保存问题和资料集合、检索追加资料、多轮带证据问答、研究笔记版本、版本比较和恢复。历史证据不可因当前资料变化而重写。

每阶段做有意义的接口与边界测试，最终编译前端、运行后端回归并部署。配置文件、模型缓存和私人资料不进入仓库。
