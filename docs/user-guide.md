# 知微使用说明（开发版）

## 当前可用功能

- 浏览文章库，按标题或摘要搜索，支持卡片/列表展示。
- 导入 UTF-8 编码的 `.md`、`.markdown` 或 `.txt` 文件（单文件不超过 10 MB）。导入后正文和 `metadata.json` 保存到资料目录。
- 创建两级本地分类，并在文章阅读页为文章指定或清除分类。
- 使用安全 Markdown 渲染器阅读导入的正文。
- 按中文标题或正文关键词搜索本地文章。
- 将问题与本地文章片段一起发送到用户配置的 OpenAI 兼容聊天接口，并显示检索来源。
- 在文章阅读页主动触发模型分类；结果必须匹配现有小类，人工选择后会锁定。
- 阅读页显示文章所属的知乎收藏夹，点击名称可打开该收藏夹；知乎回答还会显示所属问题，点击问题标题可打开问题页。本地分类下的“查看该主题文章”可打开同主题文章列表。
- 在同步中心或主题分类页批量整理主题；本地规则无法确定时会自动调用设置中配置的大模型，模型仍不确定的文章保留为“待整理”。
- 在同步中心使用知乎 App 扫描网页二维码登录，无需服务器图形桌面。登录后可刷新收藏夹、选择同步范围并启动任务。
- 通过设置输入本地资料目录。改目录会切换到该目录的资料库，不会自动搬运原有内容。

收藏夹和条目分页、正文与图片保存的同步代码已经接通扫码和浏览器会话；知乎接口返回格式仍需用本人账号实测。若接口拒绝访问或格式变化，任务会显示失败原因。批量整理任务会先在本地读取文章并尝试规则分类；配置了聊天模型时，无法确定的文章会把标题和最多 7000 字正文发送给模型。任务进度会保存，刷新页面或重启后可重试失败项。当前问答是基于关键词重叠的本地片段检索，不是向量语义检索。

## 安装和启动

需要 Python 3.11+、Node.js 20+。首次安装：

```bash
cd backend
python3 -m venv .venv
.venv/bin/pip install -e .
.venv/bin/python -m playwright install chromium
cd ../frontend
npm install
```

本机单机使用时，分别在两个终端启动服务：

```bash
cd backend
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8010
```

```bash
cd frontend
npm run dev -- --host 127.0.0.1 --port 5173
```

打开 `http://127.0.0.1:5173`。如果需要让同一局域网的其他设备访问，先运行 `cd frontend && npm run build`，然后在后端目录通过以下方式启动：

通过 Tailscale 使用前端开发服务时，让 Vite 监听服务器的 Tailscale IP，并把该地址作为后端允许的来源。例如将 `<Tailscale IP>` 替换为服务器的实际地址：

```bash
cd backend
ZHILIB_ALLOW_REMOTE=1 ZHILIB_ALLOWED_ORIGINS=http://<Tailscale IP>:5173 python3 -m uvicorn app.main:app --host 127.0.0.1 --port 8010
```

```bash
cd frontend
npm run dev -- --host <Tailscale IP> --port 5173
```

远程浏览器访问 `http://<Tailscale IP>:5173`。浏览器登录还要求后端进程继承服务器桌面会话的 `DISPLAY` 和 `XAUTHORITY`。

如果使用构建后的前端，由后端直接提供页面：

```bash
ZHILIB_ALLOW_REMOTE=1 .venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8010
```

在运行服务器的电脑上查询局域网 IP（Linux/macOS 可用 `hostname -I` 或 `ipconfig getifaddr en0`），其他设备打开 `http://局域网IP:8010`。确保系统防火墙允许 TCP 8010。远程开关默认关闭；启用后，同一网络可访问并操作文章库和设置，因此只在可信的私人局域网使用，勿将端口转发到公网。

后端默认资料目录为 `~/Documents/ZhihuLibrary`；也可在“设置”中输入本机可写目录。新的页面内登录入口使用 Xvfb 和普通 Chrome，无需服务器桌面；缺少这些依赖时会提示无法启动。生产前端可先运行 `npm run build`，再由后端提供 `frontend/dist`。

## 导入文章与分类

在文章库选择“导入 Markdown”，文件名会作为默认标题，正文第一个一级标题优先作为文章标题。文章保存到 `articles/local_<随机ID>/article.md`。导入文件内的相对图片不会自动复制，图片资源导入功能尚未实现。打开文章后可从“本地分类”选择已有分类。分类管理中创建一级分类，或为一级分类添加子分类；删除分类时可把文章迁移到其他分类或待整理。

同步完成后，在同步任务旁点击“自动整理主题”，或进入“主题分类”点击“整理新增文章”。首次整理会处理尚未整理的已有文章；以后再次点击只处理新增加且未进入过分类任务的文章。已归类或留在“待整理”的旧文章不会重跑，正文变化也不会自动重新归类。任务先用本地规则；规则证据不足或冲突、且已配置聊天模型时，自动调用模型辅助归类。模型明确表示不确定时仍留在“待整理”；模型请求或结果无效时记录失败，可在原任务中点击“重试”。每篇文章独立读取和保存，单篇失败不会中止其他文章。可在文章库左侧点击“待整理”查看清单，进入阅读页手动选择并锁定。预置分类包含数学、硬件、书籍、哲学宗教、内容创作和情感关系等小类；旧资料库会一次性补入这些小类。

分类任务结束后，主题计数与文章列表会刷新。文章卡片和阅读页显示“大类 / 小类”完整路径，便于核对归类结果。

## 知乎登录状态

在“同步中心”点击“登录知乎”。知微会在服务器的私有虚拟显示器中打开普通 Chrome，并在弹窗内显示知乎页面；服务器无需安装完整图形桌面。若知乎先要求安全验证，请在弹窗中的画面完成，之后用知乎 App 扫描显示的二维码并在手机上确认。账号验证成功后，页面会自动更新状态，再点击“刷新收藏夹”确认可读取列表并启动同步。应用不会索取知乎密码。

目前此新入口已实测能在无桌面环境中显示知乎的安全验证页，但尚未由账号本人完成验证、扫码和会话重启恢复。知乎仍可能阻止当前服务器的网络环境；页面会显示实际状态，不能将“已出现登录画面”视为“已登录”。若验证画面缩小，可点击“放大画面”。

已验证的浏览器会话保存在当前用户私有应用目录；启动时会向知乎重新校验，临时网络故障不应直接清除会话。只有账号真实有效且收藏夹接口可读取时才可同步。旧直接扫码 API 和需要服务器桌面的浏览器接口暂时保留作为兼容入口，新用户请使用同步中心的统一“登录知乎”按钮。

服务器需安装 `Xvfb`、`xauth` 和普通 Google Chrome；后端运行用户须能创建私有应用目录。虚拟显示器、Chrome 调试端口不对外开放。公司电脑只访问知微网页，无需访问 VNC 或服务器桌面。远程部署仅用于可信私人网络；登录画面和控制接口由临时令牌保护。

## 知识库问答与模型配置

在“设置”填写 OpenAI 兼容 API 地址和聊天模型名；API Key 可选，保存在本机权限受限的配置文件。提交问题时，系统按关键词检索本地文章，再把问题和相关片段发送到所填地址；点击“智能分类”或批量整理遇到规则无法确定的文章时，会发送文章标题及最多 7000 字正文。未找到问答片段时不请求模型。当前只支持关键词片段检索，尚未建立 Embedding 向量索引；Embedding 模型字段目前仅预留。请只配置自己信任的服务，并确认允许发送对应文章内容。

## 本地数据和限制

资料库中的文章、元数据和 SQLite 数据保存在所选目录；浏览器会话和模型 API Key 保存在用户私有应用数据目录。请备份资料目录并保护本机账号权限。当前没有自动清理远端取消收藏的本地文章，也没有向量语义检索。不要把含私人文章的资料目录提交到 Git。

## 阅读工作区

打开文章后可在正文中选择文字并添加高亮，可编辑颜色和批注；页面也提供独立个人笔记，离开编辑框后自动保存。侧栏“我的笔记”支持搜索笔记和原文引用，并可回到对应文章。正文更新后，系统会尝试按原文在新版本中重新定位高亮；无法唯一定位时会保留记录并提示锚点失效。首版可标注段落、列表项和引用，代码块及复杂表格暂不可标注。

阅读页 AI 面板支持全文总结、解释当前选区和提取要点。任务与结果会保存，可查看历史、取消或重试，也可将结果转为独立个人笔记。使用前需在“设置”配置聊天模型；请求只携带当前文章版本。单篇阅读记录可导出 JSON、预览并恢复到同一篇已存在文章。AI 上下文有处理上限，超限时会提示；阅读记录导出不是完整资料库备份。当前为单进程任务执行，复杂锚点人工绑定和跨文章导入尚未提供。


## 话题汇总

侧栏进入“话题汇总”，按知乎问题查看已收藏回答。首次启动会自动回填已有回答；需要修复时点击“回填已有回答”。可搜索问题、按本地分类筛选，或只看待整理。打开话题可查看知乎原问题和本地回答，并手动确认话题分类。话题分类独立于文章分类。

专栏文章只有确定属于某问题时才关联：在话题汇总页输入标准知乎问题链接（`https://www.zhihu.com/question/数字ID`）和文章库中的本地文章 ID。详情页可解除手动关联。点击“整理话题”会将问题标题和有限的本地回答摘要发送给已配置的聊天模型；界面展示进度、失败及重试。人工确认的分类不会被自动整理覆盖。


## 文章库浏览

文章库默认按最后同步时间倒序排列；正文未变化但已完成同步检查的内容，也会更新同步时间。同一轮同步按真实收藏时间倒序排列，最新收藏优先显示；本地导入排在已同步内容之后。可切换为标题排序，排序覆盖全部搜索结果。顶部搜索框支持搜索文章标题和正文。文章库与话题汇总使用统一分页：可通过“每页条数”下拉选择分页大小，修改后回到第一页；显示当前页和总页数，点击上一页、页码或下一页，也可输入有效页码后点击“跳转”。


### 删除本地文章

文章库的每张文章卡片右上角有删除按钮，列表视图同样支持；文章阅读页顶部也提供“删除文章”按钮，删除成功后返回文章库。删除前会显示确认弹窗，支持取消或按 Esc 关闭；删除期间按钮禁用，失败时可在弹窗内重试。确认后会永久删除该文章的本地 Markdown、图片和元数据，并清除搜索记录、收藏夹及话题关联。删除不会取消知乎上的收藏。

删除记录保存在当前资料库的 SQLite 数据库中；以后的增量和全量同步都会跳过该文章，即使它出现在其他收藏夹。删除记录随资料库备份保留，不会影响其他资料目录。当前不提供撤销删除；请在确认前备份需要保留的文件。

## 阅读笔记与高亮

打开文章后，在正文中选择同一段内的文字，可以保存高亮并添加批注。阅读页下方的“高亮与笔记”面板可新建多条个人笔记；笔记会自动保存，状态显示在编辑框下方。切换笔记前请等待保存完成。你可以在左侧“我的笔记”中搜索个人文字；勾选“包含原文引用”后，也会搜索高亮的原文。点击搜索结果可回到文章。正文更新后，系统会依据引用文字和上下文尝试重新定位；无法确定时会标记位置失效，可在正文重新选中文字后手动绑定。

笔记面板提供本篇阅读记录的 JSON 导出和恢复。导入前会显示标注、笔记及 AI 结果的数量，并要求确认。恢复目标须是文章库中已有的文章；导出的正文版本和引用一并保存，不包含模型 API Key。

## 单篇 AI 阅读助手

在文章页选择“AI 阅读助手”，可请求总结全文、解释选中段落或提取要点。解释段落前先在正文选择文字。只有点击操作后才会把当前文章内容发送给设置中配置的聊天模型；OpenCode 等本机模型配置也可能连接云端服务。超长文章会按段落分段分析，超过当前处理上限时页面会说明原因。

生成的结果会自动保存到该文章，并在 AI 面板中显示历史记录。相同正文版本和操作会优先复用既有结果；点击“重新生成”会发起新任务。任务支持查看进度、取消和重试；服务重启中断后可手动重试。AI 结果按生成时的正文版本保留，可转存为个人笔记；转存后编辑笔记不会改变原始 AI 结果。

## 跨文章与笔记研究

「知识问答」支持统一检索文章、笔记和批注。查找资料后勾选至少两份不同资料，可生成带出处的研究笔记；核对后保存到「我的笔记」，或导出含证据快照的 Markdown。详细步骤与模型发送范围见 [统一检索与研究笔记](knowledge-research.md)。

## 多标签工作区

“同步中心”入口位于左侧工作区主菜单，点击后打开同步中心标签。窄屏时显示向下箭头图标，悬停可查看名称。

点击左侧“话题汇总”“主题分类”“知识问答”等菜单，会在右侧顶部打开标签。重复点击会选中已有标签；打开文章或话题详情会显示独立标签和对应标题。

- 点击标签切换页面，当前输入、筛选和分页在切换时保留。
- 点击标签右侧 × 或鼠标中键关闭，当前标签关闭后会选中相邻页面。“文章库”固定保留。
- 右侧标签数量按钮可关闭其他或全部标签；标签较多时横向滚动，也可使用两端箭头。
- 标签获得键盘焦点时，左右方向键切换，Home/End 跳到首尾，Delete 关闭当前标签；Esc 收起标签操作菜单。

关闭标签或刷新页面前，请保存需要保留的笔记和研究内容。刷新后打开当前网址对应的页面，未保存的输入不会恢复。

“我的主题”底部的“待整理”右侧显示未分类文章总数，与点击后打开的待整理列表一致；分类、导入、删除和同步完成后更新。数量正在读取或读取失败时显示“—”。


## 知识空间与持续研究

「知识问答」支持语义与关键词融合检索，可建立索引并保存正确资料标签做效果对比。
左侧新增「知识空间」，包括「主题与链接」「Markdown 互通」「持续研究」。可维护双向链接主题页、用 Obsidian 编辑导出的资料、保存证据集继续追问，研究笔记支持历史比较和恢复。
具体操作、导入条件及模型限制见 [检索、知识链接与持续研究](knowledge-research.md)。

### 研究笔记草稿在哪里

在“知识空间 → 持续研究”点击“生成新的研究笔记”后，生成内容已保存为待审阅草稿，可通过成功提示中的“查看我的笔记”进入。“我的笔记”下方的“研究笔记”区同时列出待审阅草稿和已保存成果，切回该标签会自动刷新。点击笔记可核对出处、编辑并保存；草稿不会自动成为已确认的正式笔记。上方数量仅统计个人笔记与批注，研究笔记单独展示。

在顶部标签上右键，选择“刷新”，只重新加载该标签的页面，其他标签保持原状态。也可在标签获得焦点后按 Shift+F10 打开菜单，Esc 收起。刷新会重置该页面尚未保存的输入，请先保存需要保留的内容。

文章库搜索栏旁的“来源”下拉框支持筛选“知乎问答”“知乎文章”“本地导入”，默认显示全部来源。来源筛选可与标题/正文搜索、主题筛选及排序组合使用，切换来源后回到第一页。
