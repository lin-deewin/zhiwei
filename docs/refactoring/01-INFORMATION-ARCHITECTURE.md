# Zhiwei V3 信息架构与导航规范

## 1. 一级导航

一级入口控制在五个：

1. **资料库**（默认首页）
2. **个人笔记**
3. **AI 助手**
4. **研究工作区**
5. **设置与同步**

侧栏底部可提供低频的帮助、数据备份和关于入口，不得将其提升为一级业务模块。

## 2. 资料库二级导航

- 全部资料
- 最近阅读
- 稍后阅读
- 收藏来源（收藏夹/来源筛选）
- 主题分类
- 待整理（低强调、可选入口）

知乎问题/话题汇总作为资料库中的一种来源视图或筛选维度，不应与文章、个人笔记混成一种内容类型。

## 3. 个人笔记二级导航

- 全部笔记
- 读书笔记
- 知识卡片
- 主题知识页
- 最近编辑

这些是视图/类型，不要求用户在创建时完成复杂分类。个人笔记可以没有链接、没有标签、没有关联文章。

## 4. 阅读器布局

桌面端：
- 左侧主导航可收缩。
- 中间正文为视觉主区域，建议最大宽度 760–840px。
- 右侧上下文面板可收起，默认展示来源与阅读工具，不应挤压正文。
- 文章信息、收藏来源、关联问题、分类、个人标注、AI 工具必须在视觉上区分。

窄屏：
- 正文单列。
- 文章信息和 AI 工具通过抽屉/面板进入。
- 高亮、批注和阅读位置操作保持可触达。

## 5. 页面职责

| 页面 | 核心任务 | 不应承担 |
|---|---|---|
| 资料库首页 | 找到下一篇要读的资料 | 展示复杂分析图表 |
| 资料列表 | 搜索、筛选、排序、批量管理 | 编辑个人知识体系 |
| 阅读器 | 专注阅读、标注、理解 | 管理全局笔记分类 |
| 个人笔记 | 创作、编辑、回顾自己的思考 | 存储或改写原始文章 |
| AI 助手 | 跨资料检索和证据问答 | 替代原文或自动发布结论 |
| 研究工作区 | 有目标的长期研究 | 普通阅读必经流程 |
| 设置与同步 | 账号、任务、模型、目录配置 | 日常内容浏览 |

## 6. 导航和交互约束

- 首页唯一默认落点为资料库。
- 文章、笔记、研究项目可多标签打开；重复打开同一稳定 ID 应聚焦已有标签。
- 标签切换不应丢失已保存的筛选、阅读位置和编辑状态。
- 未保存笔记离开时必须提示或可靠自动保存。
- 同步任务与页面生命周期解耦。
- 低频管理动作放入上下文菜单，不在每个卡片上堆叠按钮。
- 不重复展示相同功能入口；一个动作必须有唯一清晰的主要入口。
