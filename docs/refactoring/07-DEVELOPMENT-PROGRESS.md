## 重要约束

1. 不直接改动或迁移生产资料库。
2. 不在没有备份和恢复演练时执行破坏性 schema 变更。
3. 外部文章与个人笔记必须保持不同实体；不强迫文章之间建立双向链接。
4. 保留现有阅读标注、个人笔记、知识链接、研究证据、Markdown 互通和同步能力。
5. 每个代码阶段都必须通过 CI；未做人工/端到端验证的功能不得标为完成。
6. 只有 E0–E7 的 P0 项、数据恢复和部署验收完成后，才申请合并到 `main`。
