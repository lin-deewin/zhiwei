## 任务执行模板

每个任务必须在任务描述中提供：
- ID、目标、优先级、依赖
- 现有实现和涉及文件
- 明确的范围内/范围外事项
- 数据/API/安全影响
- 验收标准和测试命令
- 回滚方式
- 完成证据与剩余问题

任务状态：Todo → In Progress → Review → Done；失败时回到 In Progress 并记录原因。不得仅凭代码已写入标记 Done。
