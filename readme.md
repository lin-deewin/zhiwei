做一个项目：项目的主要功能是将来个人知乎账号的收藏夹文章做一个整理归纳。 要有这么几个功能
1. 系统可以登陆个人知乎账号，做收藏夹文章的下载
2. 知乎文章的同步功能： 1， 有一个全量同步的按钮， 和一个增量同步的按钮， 可以看到同步的详细情况，包括一共有的文章，同步了多少； 文章同步的时候要有让用户自己选择同步的路径； 文章同步要把图片也下载， 文章保存微md文档； 
3. 系统对下载好的文章要有主题整理的功能。 就是说这些文章设计到什么主题，要做一个分类整理。 可以在系统中预先设置主题， 然后分析每一篇文章属于什么大类，属于什么小类，最好分类。
4. 点击查看每一篇文章，要有一个美观的阅读界面，特别是要注意排版美观，展示出图片。 看文章的时候，要能追溯到这篇文章是什么话题， 就是这篇文章是什么话题下收藏的。 点击这个话题可以跳转到知乎该话题的。目的是为了，在这个话题下继续发现好文章。
5. 要有搜索的功能， 做RAG
